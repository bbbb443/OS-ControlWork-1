# Контрольна робота № 1 з дисципліни «Операційні системи»

## Варіант 3. Складська логістика

Комірник має застрахувати стелаж, підійти до стелажа, змонтувати стелаж та інспектувати стелаж. Для роботи з коробкою слід зареєструвати коробку, розкрити коробку, переставити коробку та зважити коробку.

## 1. Предметні аналоги об’єктів файлової системи

| UML-роль | Сутність | Обґрунтування |
| --- | --- | --- |
| Actor | Комірник | Виконує всі наведені дії над стелажами та коробками. |
| Aggregate | Стелаж | Містить коробки; аналог каталогу. |
| Part | Коробка | Окремий об’єкт, розміщений на стелажі; аналог файлу. |

**Тип зв’язку — агрегація.** Коробка може існувати поза стелажем та бути переставлена на інший стелаж. Демонтаж стелажа сам по собі не означає знищення коробок. Команда `rm -r` у файловій системі видаляє каталог разом із вмістом; це окрема каскадна операція, яка відповідала б знищенню стелажа разом із коробками. Такої дії в описі немає, тому `rm -r` не зіставляється з жодною дією ПрО. Можливість каскадного видалення файлів не визначає життєвий цикл реальних коробок.

Кратність агрегації: біля стелажа `0..1`, біля коробки `0..*`: стелаж містить нуль або багато коробок; коробка в певний момент належить щонайбільше одному стелажу, але може перебувати поза ним.

Для кожної іменованої асоціації прийнято кратності `1` біля комірника та `0..*` біля об’єкта. У межах навчальної моделі один відповідальний комірник працює з довільною кількістю стелажів і коробок. Це припущення моделі: опис не визначає кількість працівників реального складу.

## 2. Семантичні відповідності

Основна таблиця містить рівно 12 рядків у порядку методички. Дві дії без відповідника подано окремо, щоб одночасно зберегти всі 12 команд і всі 8 дій ПрО. У прикладі методички ці вимоги суперечливо поєднані: пропущено `rm -r` і `rm`.

| Операція ПрО | Операція Bash-команди | Bash-команда | Обґрунтування вибору |
| --- | --- | --- | --- |
| підійти до стелажа | перейти у каталог (Aggregate) | `cd` | Перехід до вибраного контейнера як місця роботи. |
| змонтувати стелаж | створити каталог (Aggregate) | `mkdir` | Поява нового контейнера для коробок. |
| зареєструвати коробку | створити файл (Part) | `touch` | Поява нового елемента в обліковій моделі. Для нового імені touch створює файл; для наявного лише оновлює часові позначки. |
| — | змінити файл (Part) | `nano` | У тексті немає дії редагування вмісту коробки. |
| інспектувати стелаж | переглянути каталог (Aggregate) | `ls` | Огляд розміщених на стелажі елементів у межах прийнятої аналогії. |
| розкрити коробку | переглянути файл (Part) | `cat` | Розкриття трактуємо як доступ до огляду вмісту, а не його редагування. cat показує вміст; фізичне відкриття пакування не моделюється. |
| переставити коробку | перемістити файл (Part); команда також підтримує Aggregate | `mv` | Зміна розташування коробки без створення копії. Переміщення самого стелажа в описі відсутнє. |
| — | створити копію каталогу (Aggregate) | `cp -r` | Копіювання стелажа з коробками не описано. Монтаж нового стелажа не є копіюванням. |
| — | створити копію файлу (Part) | `cp` | Дублювання коробки не описано. |
| — | видалити порожній каталог (Aggregate) | `rmdir` | Вилучення порожнього стелажа не описано. |
| — | видалити каталог разом із вмістом (Aggregate) | `rm -r` | Знищення стелажа разом із коробками не описано. |
| — | видалити файл (Part) | `rm` | Вилучення коробки не описано. Переставляння зберігає її існування. |

### Дії без семантичного відповідника

| Операція ПрО | Операція Bash-команди | Bash-команда | Обґрунтування вибору |
| --- | --- | --- | --- |
| застрахувати стелаж (Aggregate) | — | — | Страхування встановлює страховий захист. Жодна з 12 операцій над каталогом не виконує такої дії; створення копії не є страхуванням. |
| зважити коробку (Part) | — | — | Вимірювання фізичної маси не є створенням, переглядом, редагуванням, копіюванням, переміщенням або видаленням файла. |

Визначено рівно одну дію без відповідника для кожного типу. Шість інших дій однозначно відповідають шести різним командам. Дублювання відсутнє.

## 3. UML-діаграма

Код: [Sklad.puml](Sklad.puml). `Sklad` — скорочена однословна назва ПрО у транслітерації, що замінює шаблон `Domain` у методичці.

Діаграма містить три класи, агрегацію та всі вісім іменованих асоціацій. Команди вказані в `note on link`; для страхування і зважування зазначено `Bash: немає`.

Для перевірки візуалізації відкрити https://www.planttext.com/ та вставити вміст Sklad.puml. Перевірити три класи, вісім дій, кратності, порожній ромб біля стелажа та коментарі до зв’язків.

## 4. Псевдоніми

Файл: [Sklad_aliases.sh](Sklad_aliases.sh). Завантажити його в поточну Bash-оболонку командою `source ./Sklad_aliases.sh`. Запуск через `bash Sklad_aliases.sh` не додає псевдоніми до батьківської оболонки.

| Дія | Псевдонім |
| --- | --- |
| підійти до стелажа | `alias pidiity='cd'` |
| змонтувати стелаж | `alias zmontuvaty='mkdir'` |
| зареєструвати коробку | `alias zareiestruvaty='touch'` |
| інспектувати стелаж | `alias inspektuvaty='ls'` |
| розкрити коробку | `alias rozkryty='cat'` |
| переставити коробку | `alias perestavyty='mv'` |

Для дій «застрахувати» та «зважити» псевдоніми не створюються.

### Відтворювана перевірка в Bash

Виконувати з каталогу OS-ControlWork-1. Усі приклади працюють у новому тимчасовому каталозі.

```bash
source ./Sklad_aliases.sh
shopt -s expand_aliases
sandbox=$(mktemp -d)
pidiity "$sandbox"
test "$PWD" = "$sandbox" || exit 1
zmontuvaty stelazh_1 stelazh_2
test -d stelazh_1 && test -d stelazh_2 || exit 1
zareiestruvaty stelazh_1/korobka.txt
test -f stelazh_1/korobka.txt || exit 1
# Допоміжна команда додає демонстраційний вміст для перевірки cat.
printf '%s\n' 'Vmist korobky: knyhy' > stelazh_1/korobka.txt
inspektuvaty stelazh_1
test "$(inspektuvaty stelazh_1)" = 'korobka.txt' || exit 1
rozkryty stelazh_1/korobka.txt
test "$(rozkryty stelazh_1/korobka.txt)" = 'Vmist korobky: knyhy' || exit 1
perestavyty stelazh_1/korobka.txt stelazh_2/korobka.txt
test ! -e stelazh_1/korobka.txt && test -f stelazh_2/korobka.txt || exit 1
test "$(rozkryty stelazh_2/korobka.txt)" = 'Vmist korobky: knyhy' || exit 1
printf '%s\n' 'Усі шість псевдонімів перевірено успішно.'
```
